## Description

This program uses the full name `KYLE GABRIEL ENAD` to create an array of
letters. Spaces are ignored, and duplicate letters are discarded. The program
then sorts the unique letters in alphabetical order using Bubble Sort.

## Arrays

- **Unsorted array:** unique letters in the order they first appear.
- **Sorted array:** the same letters arranged alphabetically.

## Algorithm

1. Start.
2. Store the full name: `KYLE GABRIEL ENAD`.
3. Convert the name to uppercase.
4. Read each character in the name.
5. Ignore spaces and any non-letter symbols.
6. Add a letter to the unsorted array only if it is not already present.
7. Copy the unsorted array to create the array that will be sorted.
8. Compare each pair of adjacent letters.
9. If the left letter comes after the right letter alphabetically, swap them.
10. Repeat the comparisons until a complete pass makes no swaps.
11. Display the unsorted array and the sorted array.
12. End.
